# orchestra-mcp/pack-native-csharp

C# and Windows native plugin development agents

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-native-csharp
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-native-csharp")
```
